# Full Stack Open

My solutions and notes for [Full Stack Open](https://fullstackopen.com/en/), a free online course on modern JavaScript-based web development from the University of Helsinki and Houston Inc.

The course focuses on building single-page applications with React that use REST APIs built with Node.js. It also covers Redux, MongoDB, GraphQL, TypeScript, and more.

## Repository structure

Each course part has its own folder:

```text
.
├── part0/
├── part1/
├── part2/
└── ...
```

## Running a project

You'll need [Node.js](https://nodejs.org/), which includes npm. Then, from the folder of the project you want to run:

```bash
npm install
npm run dev
```

Some projects may use a different start command. Check the `scripts` section of each project's `package.json`.
