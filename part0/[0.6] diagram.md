# 0.6: New note in single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user types a note and clicks Save
    Note right of browser: The JavaScript prevents the default form submission, adds the note to the list, and redraws the notes

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (JSON with content and date)
    activate server
    Note left of server: The server saves the new note
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: The browser stays on the same page and sends no further requests
```
